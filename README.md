# Ace Pen Studio Website

This repository contains the source files for the official Ace Pen Studio website, hosted through GitHub Pages.

## About Ace Pen Studio

**Ace Pen Studio is a consultancy studio and creative hub based in Tanzania.**

Where stories are articulated and visions executed.

We work at the intersection of literature, writing, creative thinking and project development. Our work brings together editorial expertise, literary representation, writing consultancy, publishing strategy and practical project execution.

We support individuals, writers and organisations in developing their ideas and bringing meaningful work to life.

Our areas of work include:

- Literary representation and editorial development
- Ghostwriting and writing consultancy
- Author development and publishing strategy
- Creative project development and coordination
- Workshops, bootcamps, literary gatherings and events
- Consultancy and strategic support for creative initiatives

We are an Africa-forward creative studio with an interest in stories, ideas and projects that contribute to meaningful cultural and professional conversations.

## Repository Structure

The repository contains the website's HTML pages, image assets and supporting files.

- `index.html` — Main homepage
- `faqs.html` — Frequently Asked Questions
- `inquiry.html` — Client inquiry page
- Image files — Photography and visual assets used throughout the website

## How to Edit the Website

1. Open the repository on GitHub.
2. Select the file you want to update, such as `index.html`.
3. Click the edit icon or upload a replacement file.
4. Make the required changes.
5. Commit your changes to the repository.
6. Allow GitHub Pages a few moments to publish the updated website.

You can also download the repository and edit the files locally using a text editor such as Visual Studio Code.

## Image Guidelines

When updating the website, please observe the following:

- Every image should be used only once across the website.
- Do not reuse an image in multiple sections.
- Preserve the existing image filenames unless the corresponding HTML references are also updated.
- Ensure image filenames and file paths match exactly, including capitalisation, spacing and file extensions.
- Optimise images for web use without compromising their quality.
